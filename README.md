## 📌 Опис проєкту
Програма реалізує алгоритм ідентифікації та розпізнавання об'єктів (автомобілів) за сукупністю:
- **Кількісних характеристик:**
  - Потужність двигуна (к.с.)
  - Споряджена маса (кг)
  - Час розгону 0-100 км/год (с)
  - Об'єм багажника (л)
- **Якісних характеристик:**
  - Тип кузова (`седан`, `кросовер`, `хетчбек`, `купе`, `мінівен`, `пікап`) — One-Hot Encoding
  - Тип палива (`бензин`, `дизель`, `електро`, `гібрид`) — One-Hot Encoding
  - Наявність повного приводу 4WD/AWD (`так`/`ні`) — бінарне кодування

Для відхилення об'єктів, які не належать до відомого алфавіту класів (аномальні об'єкти), використовується порогове значення $THRESHOLD = 1.05$.
